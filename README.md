# Diamond Helper Mod

A versatile diamond block mod for Minecraft Bedrock.

## Features

- Adds a diamond helper block
- Provides a menu with options for mining, farming, and building

## Requirements

- Minecraft Bedrock Edition 1.20.1
- Forge 43.1.0

## Installation

1. Download the mod from the releases page.
2. Place the mod file in your mods folder.
3. Launch Minecraft Bedrock Edition.

## Usage

1. Place the diamond helper block in your world.
2. Right-click the block to open the menu.
3. Choose an option from the menu to perform actions related to mining, farming, or building.
